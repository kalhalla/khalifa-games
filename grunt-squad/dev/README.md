# Grunt Squad — version history

The game's working file, one commit per version, tagged `grunt-squad-vNN`.
This branch is the archive; `main` carries only what is live at khalifa.games/grunt-squad/.

- Get any version: `git show grunt-squad-v52:grunt-squad/dev/grunt-squad-3d.html > v52.html`
- The live page (`grunt-squad/index.html` on `main`) is this file spliced after the site's own `<head>`.
- The claude.ai project keeps only the current version.

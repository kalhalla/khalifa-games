# Grunt Squad — version history

The game's working file, one commit per version, each titled "Grunt Squad vNN (working file)".
This branch is the archive; `main` carries only what is live at khalifa.games/grunt-squad/.

- List versions: `git log --oneline grunt-squad-dev -- grunt-squad/dev/grunt-squad-3d.html`
- Get one: `git show <commit>:grunt-squad/dev/grunt-squad-3d.html > v52.html`, or open the file at that commit on GitHub and download it.
- The live page (`grunt-squad/index.html` on `main`) is this file spliced after the site's own `<head>`.
- The claude.ai project keeps only the current version.
